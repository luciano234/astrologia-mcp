# Publish on mcp.so / Publicar en mcp.so

**Where / Dónde:** https://mcp.so/submit (sign in with GitHub / inicia sesión con GitHub).

**EN:** mcp.so does not receive files: it displays the repository's `README.md`
from GitHub. Push the changes before submitting the form.

**ES:** mcp.so no recibe archivos: muestra el `README.md` del repositorio de
GitHub. Sube los cambios (push) antes de enviar el formulario.

## Form data / Datos para el formulario

| Field / Campo | Value / Valor |
|---|---|
| **Type** | MCP Server |
| **Name** | Astrologia MCP |
| **URL** | https://github.com/luciano234/astrologia-mcp |
| **Server Config** | [`server-config.json`](server-config.json) |
| **Tags** | astrology, horoscope, natal-chart, spanish, english, cosmyday |

**Description (EN):**

> Bilingual (English/Spanish) MCP server for astrology: natal charts, today's
> transits, moon phase, upcoming sky events and daily/weekly/monthly
> horoscopes, powered by the public CosmyDay API (https://cosmyday.com). No API
> key required.

**Descripción (ES):**

> Servidor MCP bilingüe (inglés/español) para astrología: cartas natales,
> tránsitos del día, fase lunar, próximos eventos celestes y horóscopos
> diarios, semanales y mensuales con datos de la API pública de CosmyDay
> (https://cosmyday.com). Sin clave de API.
